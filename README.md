# Gym-Management-System

Objective:
Develop an integrated digital system to support gym owners and staff in managing daily operations efficiently, including facilities, equipment, personnel, members, and workout packages.

Main Features:
- Manage gym rooms and equipment (track status, maintenance);
- Handle member registration, packages, and workout history;
- Member accounts to register, view, and note workout schedules;
- Trainers manage their assigned members, track progress, and provide guidance;
- Support different user roles: owner, manager, trainer, member;
- Provide reports on revenue, attendance, and staff performance.

Technologies:
- Frontend: React.js, Tailwind/CSS
- Backend: Node.js, Express.js
- Database: MongoDB
